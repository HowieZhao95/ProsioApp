# Prosio 每日便签：A 极简浮窗第二稿

2026-10-02 · 用户已选择A方向。本轮按新增要求更新设计，尚未实现生产功能。

## 已确认的方向与新增要求

- 采用A极简浮窗。
- 存储位置只在设置里选择，不在便签面板选择。
- 每天只有一张便签，日历切换日期，能快速回到今天。
- 用户输入的「变迁」按上下文理解为「便签」。

## 1. 主界面

窗口默认约420×510pt，保留原生浅色面板、系统字体、内容优先。默认置顶，可取消；正文不透明，失焦保持显示且不抢焦点。

标题栏从左到右：隐藏按钮、日期按钮、回到今天（仅历史日期显示）、置顶。日期示例「10月2日 周五 · 今天」。点击日期按钮展开日历；平时日历完全收起，不挤占书写区。

正文保持所见即所得Markdown编辑。底部只放保存状态、失败时的重试、格式/更多菜单（Aa）。没有选择位置、另存为、文件名输入或新建便签按钮。

「Aa」含格式操作、源码模式、便签设置。主应用设置中也有「便签」分组；两处打开同一设置页，浮窗中的入口只是导航到设置，不弹出文件选择器。

隐藏、⌘W和当前聚焦时再次快捷键都隐藏窗口；再唤出恢复当前日期、正文和光标。重新启动应用后的首次唤出建议打开今天；跨午夜、窗口已打开或正在书写时保留所选日期，避免把昨天内容写入今天。

## 2. 日历组件

日期按钮下方展开300pt左右的月份弹层，包含月份标题、上/下月、周一至周日的7列日期、回到今天。

- 蓝色实底：正在查看的日期。
- 细描边：今天。如果今天就是选中日期，用实底，辅助语义仍标记今天。
- 小圆点：该日期存在非空内容，包括尚未写入正式目录的草稿。
- 无圆点：未记录或内容为空。仍可选择历史空白日期，直接写。
- 本版建议未来日期不可选择，未来日灰显；下一月入口不能超过当前月份。这是设计建议，不是用户明确提出的限制。
- 点击日期后收起日历，保留旧日的内容，加载新日唯一便签；无内容时显示「这一天还没有记录，写点什么…」。
- 日历底部始终有「回到今天」。历史日标题栏也显示同名动作，不必再次展开日历。
- 查看某个月份不等于切换活动便签；只有选择日期或回到今天才改变正文。
- 点弹层外或Esc只收起日历；再按Esc才隐藏窗口。中文候选存在时，Esc交给输入法。

历史日期允许继续编辑，不做只读日记。不提供同一天的第二张便签；当天的多个段落、任务和标题都写在同一份内容内。

## 3. 存储位置在设置里选

「设置 → 便签 → 存储位置」显示目录和「选择文件夹…」。它打开系统文件夹选择器，仅选择文件夹，不要求每天选文件名。

正式文件统一命名为 `YYYY-MM-DD.md`，例如所选目录中的 `2026-10-02.md`。不使用正文标题命名；一个本地日期只能有一个对应文件。

第一次未配置：

1. 可以先写，底部显示「草稿已保留 · 未设置存储目录」。
2. 日期间切换同样可用，各天草稿独立保留。
3. 通过设置手动选择文件夹。成功验证可写后，将所有有内容的日期草稿保存到对应日期文件，清除相应草稿未保存标记。
4. 用户取消选择不改变目录，也不丢草稿。未选目录时⌘S只提交恢复副本并提示去设置，不在面板弹出位置选择。
5. 空白日期不因查看或打开而生成新文件；已经存在的文件被用户清空时仍保存为空文件，不自动删除。

设置的其它项目：外观（正式版跟随系统/浅色/深色）、正文大小14/16/18pt、全局快捷键、默认置顶。演示版只提供浅/深主题与字号，快捷键为候选说明。

## 4. 更换目录

更换目录须处理原有内容，不能简单改路径并让历史突然消失。

选好新目录后显示：

- **迁移便签（建议）**：把当前目录的日期文件及待保存内容复制到新目录，核验后切换。原文件保留。发现同日期不同内容时停止并列出冲突，不覆盖。
- **仅切换目录**：使用目标目录已有的每日便签，原目录内容保持原样；旧目录草稿继续绑定旧目录，切回后可恢复。
- **取消**：保留当前目录及活动内容。

当前日未保存或目录失效时，迁移必须从恢复快照取得最新内容；目录验证、复制或核验失败都不提交新目录配置，显示具体错误。首次把草稿写入目标文件夹时同样要检查日期文件冲突，不能覆盖既有文件。

「一天一张」的约束在一个选定目录内成立。仅切换目录是显式切换另一组便签，不是同时维护两个活动目录。

## 5. 日期与保存逻辑

文档标识为「目录身份 + 本地日期」，不以标题或切换次数标识。未设置目录时用独立草稿命名空间；文档ID、日期与编辑版本随保存任务一起携带。

日期按用户系统本地时区确定。切换时区仅改变“今天”的定义，旧文件的日期不会重新命名。跨午夜时：

- 已打开窗口保持当前日及光标，标题真实显示其日期，自动出现「回到今天」。
- 已隐藏的同一应用会话再次唤出，保留上次选择并显示回到今天。
- 新应用会话首次唤出默认今天；旧日未保存内容仍在恢复副本中，并标注需要恢复。

编辑停止约1秒后保存，中文组合输入结束后才序列化。当前日保存任务完成回调不许更新别的日期的状态；旧版本回调不许把新版标成已保存。

切换日期前先提交当前最新版本。成功后加载所选日期；未选目录时写恢复副本后切换。写入失败：保留正文和所选日期，显示「未能保存 · 内容已保留」，提供重试；用户可去设置修复或迁移目录。当前审核稿建议先处理失败再切换日期，减少隐藏未保存内容的风险。

浏览器原型用同步演示状态模拟切换前提交；生产版必须等待原生保存结果，不能用原型逻辑替代真实磁盘事务。

## 6. 状态与异常

| 状态 | 面板响应 |
|---|---|
| 未设置目录 | 草稿已保留 · 未设置存储目录 |
| 初次查看空白日期 | 空白便签 · 写入后自动保存 |
| 已编辑 | 有未保存更改 |
| 写入中 | 保存中… |
| 最新版本成功 | 已保存 |
| 写入失败 | 未能保存 · 内容已保留；重试 |
| 当前文件被外部修改 | 文件在别处已修改；停止覆盖，处理冲突 |
| 目录不可访问 | 存储目录无法访问；重试或前往设置 |

外部修改冲突仍使用查看磁盘版本、保留当前副本、取消的保护策略，不能创建同日期第二份主文件。冲突备份放应用恢复区，不作为日历上的第二张便签。Markdown未知语法/HTML优先源码保留，不静默删改。

未命名概念被「未配置目录的日期草稿」取代。不提供任意新建、任意打开、每张另存为或文件重命名；这些会破坏日期与文件的一一对应关系。

## 7. 原生实现分工与验收

窗口控制器负责显示、焦点、置顶、屏幕位置。每日便签协调器负责今天、所选日期、目录身份及保存状态。原生存储层负责目录权限、按日期文件、串行原子写入、恢复副本、文件监测与迁移冲突。Milkdown只负责当前日Markdown编辑，日期切换前先取得最新编辑快照。

验收：同一天反复唤出/选择只打开同一个文件；跨日内容不串写；设置取消不改变目录；多日草稿在配置目录后可靠落盘；保存时继续输入/切日不误标保存；未保存失败处理可恢复；日历月份导航、今天、圆点、空白日期、未来不可选均一致；跨午夜不切走正文；中文候选Esc不误隐藏；换目录冲突不覆盖；原生全屏、多桌面、外接屏恢复另行真机验证。
