# 每日便签设计审核稿 · A 第二稿

打开index.html进入最新审核页，点击打开完整交互原型（a-v2.html）。文件可离线直接打开。design.md是当前完整体验/UI/状态逻辑说明，direction-approved.md记录用户选择与新增要求。

每天一张便签；日期按钮展开日历；历史日可编辑并可快速回到今天；目录只在设置中选择，文件按日期命名。未选目录时，各天内容作为草稿保留。目录迁移/切换在设置内模拟，冲突不覆盖。

原型固定2026-10-02并使用演示文案与路径。localStorage只保存浏览器审核演示，不调用真实系统置顶/快捷键、不选择实际文件夹、不创建.md文件，不是Milkdown生产编辑器。

可操作：日历月份、日切换、回到今天、各日独立编辑/源码、主题与字号、设置选择目录/取消、迁移/仅切换、未设置目录、保存失败/重试、隐藏/恢复。

图片：overview-v2.png为新版审核概览；a-v2.png为完整浅色；a-v2-window.png、a-v2-calendar-window.png、a-v2-settings-dialog.png为三处界面；a-v2-dark-calendar.png为深色日历。

旧稿保留：index-v1.html、a-v1.html、design-v1.md、spec-v1.md；旧B/C与图片保留作为设计过程记录。
