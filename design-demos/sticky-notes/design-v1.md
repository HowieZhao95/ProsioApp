# Prosio 便签：体验与逻辑设计稿

版本：审核初稿 · 2026-10-02

状态：技术方案已确认；本文的产品范围、交互和三个视觉方向待审核。本轮仅交付设计与可点击原型。

## 1. 产品定位

随时叫出来、直接写、放在其它窗口上方参考的轻量 Markdown 记事本。便签服务正在进行的工作，而不是把用户带进笔记管理系统。

目标体验：从任何应用调出后立即输入；切回原应用仍能看到内容；用户明确决定文件放在哪里；保存状态可信；隐藏、误关和保存失败都不轻易丢内容。

建议第一版：一个活动便签、基础 Markdown、置顶、快捷键、文件打开/另存为、草稿恢复。暂不包含多便签墙、标签、搜索、同步、图片附件、AI整理。仍可切换多个文件，区别在于一次只编辑和显示一个。

## 2. 从入口到保存

### 2.1 入口

- 在 Prosio 菜单的共用底部增加一行「便签　⌃⌥N」，位于设置区之前。它直接打开便签；不挤进现有五个功能标签，也不需要先切页。
- 全局快捷键候选为 ⌃⌥N，可在设置中修改。实际注册时检测冲突；失败显示具体提示，菜单入口始终可用。
- 隐藏时按快捷键：显示并聚焦。已显示、正在其它应用工作时按：聚焦便签。便签已聚焦时再按：隐藏。
- 默认唤出最后活动文件或草稿；首次使用显示空白草稿，无欢迎弹层。编辑器就绪后将光标放入正文，保留再唤出时的光标、选区和滚动位置。

### 2.2 首次书写

窗口标题「未命名便签」，正文占位「写点什么…」。底部显示「未选择保存位置」以及「选择位置…」。可以直接写，暂时不选路径。

应用维护本地恢复副本，底部绝不把它称为「已保存到文件」。首次草稿状态可显示「草稿已保留」，信息帮助中解释恢复副本仅用于避免丢失内容。

### 2.3 正式保存

点击「选择位置…」或 ⌘S，打开系统保存面板。建议文件名来自正文第一行（截断过长内容、去掉路径字符、加.md后缀），用户可编辑；建议目录可以是上次手动选择的目录，但不能未经选择就写入。

取消面板：保留原草稿、光标和路径未选择状态。确认面板：写入成功后才更新文件名、路径和「已保存」；写入失败不显示成功。

首次保存后，编辑停止约1秒便自动保存到选定文件。⌘S立即提交最新内容。⌘⇧S打开「另存为…」；成功后活动便签转向新路径，原文件保留。底部路径可点击，在Finder中显示；完整路径只在悬停提示或文件详情中展示，窄窗口中不挤压保存状态。

### 2.4 返回工作

默认置顶，点击原应用继续工作时便签留在原处，不自动隐藏或抢回焦点。切换应用不触发系统通知和保存成功弹窗。

「×」、⌘W与聚焦时的唤出快捷键都隐藏便签，标题提示「隐藏便签」。Esc先关闭当前菜单或弹层，中文输入候选存在时优先交给输入法；其它情况下隐藏。隐藏不删除文件，不丢草稿。

应用启动时恢复内容与窗口偏好，但不自动把便签显示在桌面上；用户调出时再显示。

## 3. 窗口与编辑交互

### 窗口

默认约420×480pt，最小320×240pt。首次在当前活动屏幕右上方显示，距离系统菜单栏及边缘24pt；可拖动和缩放，下次记住位置。这里「置顶」指显示在其它普通窗口上方，位置可以自由调整，并非强制停在屏幕顶端。

置顶开关有可见的选中状态和「置顶／取消置顶」提示。取消后变为普通窗口，在后台可能被其它窗口遮挡。正文始终不透明，不因失焦降低透明度，确保参考内容易读。

记忆置顶状态、窗口大小和位置。外接屏断开后将窗口恢复到可见屏幕范围；不让窗口出现在不可操作的屏外。跨桌面和全屏显示按macOS允许的浮窗行为实现，需真机验证，不能承诺盖住所有系统弹层。

### 编辑

所见即所得为默认模式。首版支持段落、H1–H3标题、加粗、斜体、删除线、链接、有序/无序列表、任务项、引用、代码块、简单表格。

- 输入「# 」转标题，「- 」转列表，「- [ ] 」转任务项；代码围栏按编辑器能力处理。
- ⌘B/⌘I加粗/斜体，⌘Z撤销、⌘⇧Z重做；链接由格式菜单创建或编辑。
- 任务复选框点击切换完成状态，立即成为一次编辑，可撤销。
- 链接在编辑时不因普通点击意外打开；⌘点击或链接菜单的「打开链接」才跳到浏览器。
- 粘贴时优先保持可表达的Markdown结构；不支持的复杂富文本降为可读文本，不能执行HTML脚本。
- 格式工具出现的位置随方向不同，但功能一致；“更多格式”承载低频功能。所有图标提供中文提示和键盘焦点。
- 源码模式位于更多菜单，是同一文档的另一种编辑视图；切换应保持内容，并将撤销行为设计成连续操作。原型只模拟切换，不能据此宣称生产编辑器已经满足这一点。

窗口标题采用文件名；正文的Markdown标题独立于文件名。修改正文第一行不会自动重命名现有文件。首版可通过另存为更改名字。

## 4. 信息布局与视觉规范

三个方向使用同一份演示文本，先比较布局，再决定风格。演示不调用系统保存面板，也不把内容写入真实.md文件；所有「保存」结果都标明为模拟。

共通规范：系统字体；正文16pt、行距约1.65；辅助文字至少12pt；正文对比度至少4.5:1。主控件点击区至少28×28pt，键盘焦点明显。浅色/深色跟随系统，也可在便签设置中固定。底部只在等待操作或异常时突出，正常保存状态保持低调。

### A · 极简浮窗（建议作为第一版基础）

标题栏只保留文件名、置顶、隐藏。正文是绝对主角；格式入口轻量，低频格式进入菜单。底部承担保存状态和手选路径。

适合快速记事、频繁唤出、持续放在桌面旁边参考。取白盒留白与原生工具的克制，避免把便签做成小型文档中心。

### B · 工具便签

沿一侧放置紧凑的常用格式工具带，正文紧邻工具；固定入口降低发现成本。底部保存状态同样明确，工具带不充当文件列表。

适合经常整理标题、任务与代码、偏好按钮操作的用户。代价是窗口横向占用稍大，正文空间少一些。

### C · 收起便签

展开时是浅暖纸色的书写窗口，底部紧凑格式区；额外提供「收起」动作。收起成屏幕上方的小条，仅显示文件名和保存状态，点击展开。

适合要长期挂在屏幕上、又不想一直挡住工作的人。收起条不展示正文预览。收起、隐藏和取消置顶是三种独立动作：收起仍可见；隐藏完全不显示；取消置顶只改变窗口层级。收起会增加状态和测试成本，是否纳入第一版由本轮审核决定。

## 5. 状态与恢复

| 状态 | 界面文案 | 用户动作/后续逻辑 |
|---|---|---|
| 首次未选路径 | 未选择保存位置 | 选择位置或继续书写 |
| 有内容的草稿 | 草稿已保留 · 未选择位置 | 选择位置；恢复副本不等于正式文件 |
| 已有文件发生编辑 | 有未保存更改 | 停止输入后自动保存；⌘S立即保存 |
| 正在写入 | 保存中… | 继续输入；下一版本排队，不阻断编辑 |
| 当前版本写入成功 | 已保存 | 显示简化文件位置 |
| 写入失败 | 未能保存 · 内容已保留 | 重试／另存为，失败状态不自动消失 |
| 外部有冲突 | 文件在别处已修改 | 查看磁盘版本／另存当前内容／取消 |
| 文件不可访问 | 原文件无法访问 | 重试／另存为，保留当前正文 |
| 恢复崩溃草稿 | 已恢复上次未保存内容 | 查看后继续写或选择位置 |

关键点：状态表示当前编辑版本，而不是上一版本。旧写入回调晚到时，不能把新编辑标成「已保存」。失败后仍可编辑，异常提示保持可见，不能用一次瞬时toast替代。

### 新建与打开

更多菜单「新建便签」「打开Markdown…」切换活动文档。已保存文件先提交最后编辑版本；提交失败时暂停切换并提供重试/另存。

非空未命名草稿切换前给出三个明确选择：「选择位置并保存」「保留草稿并继续」「取消」。保留的草稿可通过「恢复草稿…」选择找回；这是恢复机制，不是完整笔记库。空白草稿切换无需确认。

非空草稿不会因隐藏、退出或保留时间自动删除。用户主动「丢弃草稿」才清理，操作须确认且不能删除原有.md文件。已命名文件也不会因新建或隐藏被删除。

### 外部编辑

文件由其它编辑器修改时，无本地改动且没有中文组合输入可重新加载；有本地改动则停止自动覆盖，先处理冲突。「查看磁盘版本」只读对比，随后可明确选择采用磁盘版本；采用前保护当前版本。取消处理时继续保留冲突状态，绝不自动恢复覆盖。

### 退出与异常

隐藏、切换和正常退出前提交最新内容，并确保恢复副本更新。已有文件写入失败但恢复副本成功，可保留失败标记供下次恢复；如果两种写入都失败，退出时明确提示「无法保存当前内容」，提供选择其它位置或取消退出，不能静默退出。

已有文件出现编辑器不支持的语法或HTML时，优先用源码模式保留内容，不静默删掉。Markdown序列化可能规范化空行与标记，需在首次相关保存时适度说明；无需每次提醒。

## 6. 设置与实现分工

在现有设置中增加便签分组：全局快捷键、默认置顶、外观（跟随系统/浅色/深色）、正文大小（14/16/18pt，默认16）。自动保存是选好位置后的默认行为，不提供可能导致误解的「关闭自动保存」开关。

设置不指定一个未经选择就写入的固定文件夹；路径由每次首次保存或另存为决定。窗口层级、文件读写、权限、快捷键、生命周期交给原生层；编辑内容和格式交给本地打包的Milkdown。系统保存对话框和Finder打开使用原生能力。

原生协调器负责文档ID、编辑版本、文件路径、保存状态与恢复；持久化层负责串行原子写入、错误、文件外部变化；窗口控制器负责显示/聚焦/置顶/位置；WebView桥接只传递已验证的内容和命令，不允许网页任意访问本地路径。

## 7. 审核与验收

本轮审核建议确认三个问题：选择哪个界面方向；第一版是否接受「一个活动便签」；保存规则是否接受「首次手选位置，之后自动保存」。其它交互按本文作为默认方案，可逐条提出调整。

后续实现验收覆盖：

1. 在其它应用中唤出、直接中文输入、失焦后置顶仍显示；不同焦点下快捷键语义一致。
2. 未选路径输入后取消保存、隐藏、重启，草稿可恢复，界面从未错误显示文件已保存。
3. 选定位置后连续输入、保存时继续输入、隐藏/退出，磁盘最终是最新版本，保存状态与之相符。
4. 无权限、磁盘错误、外部修改/删除、未支持语法均不静默丢内容。
5. 中文候选框Esc、快捷键冲突、窗口最小尺寸、深色、高对比、键盘导航、外接屏断开、macOS全屏/多桌面分别通过验证。

交付物为审核设计稿，尚未接入真实Milkdown、全局快捷键、系统保存面板或文件读写。方向选定后再整理对应全部界面状态与实现定稿。
