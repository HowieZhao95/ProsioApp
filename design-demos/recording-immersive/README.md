# 沉浸式录屏 · 三方向交互初稿

双击 index.html 比较三个方向，点击预览进入；也可以直接打开 a.html、b.html、c.html。所有图片均内嵌，无需服务端和网络。原型使用模拟桌面与摄像头示意照片，不请求设备权限，不实际录制，不打开编辑器。

A：底部悬浮工具栏，机位预览独立浮在屏幕右侧。最接近用户指定的系统录制体验，推荐作为实施方向。
B：工具栏贴近选中的窗口，预览排列在窗口外侧。
C：预览与工具条聚成一体，开拍前集中查看构图。

可以体验：屏幕/窗口/区域图标切换，窗口悬停高亮和点选锁定，区域鼠标拖拽，两路摄像头开关与第三路上限，预览拖动，独立声音开关，倒计时，录制中的简洁控制，暂停和停止，再次录制。录制中的关闭预览只隐藏画面，不删除原片来源。

本轮只交付设计原型，没有替换生产 SwiftUI 界面。等待用户选择方向后，才把已实现的采集、原片保存和软件交接接入这种桌面浮层体验。具体设计依据见 spec.md；示例素材边界见 product-facts.md。
