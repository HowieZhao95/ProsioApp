# Prosio 订阅与额度 UI 共同设计规格

状态：设计提案，等待用户选择，不代表已批准实施。此次先交付三个可点击方向，确认后才修改 SwiftUI、支付和计费代码。

Prosio 是已有的 macOS 菜单栏听写工具，并非新的营销网站。主要使用情景是用户在任意应用中按快捷键说话，再得到可编辑文字。商业化界面应该解释服务差别、账户和额度，同时保持日常听写不中断。用户希望以每月 US$9.90 收费，采用 Stripe 支付，提供每个订阅月 600 分钟云端转录；用完后自动使用本地听写，仍能继续输入。我们需要使「不限量」准确指向本地听写，不能暗示无限云端 AI，也不能把用户悄悄切换而不解释差异。界面要温和、明确、有原生工具的克制感，避免仪表盘式冗余统计、营销大标题和复杂套餐比较。基于这个理解，直接做三个不同方向的真实版本供用户选择。

## 真实上下文与资产
现有 SettingsRootView 使用 520×460 窗口，上方四页签：通用、词典、历史、账户。账户页为 grouped Form。MenuBarContentView 约320宽。字体使用 macOS SF / 苹方系统字体；黑白灰为主、系统蓝作为操作强调。ProsioPalette 只有稀疏粉色 #FF6778 和蓝紫 #8D99FF 点缀。代码中品牌为 waveform SF Symbol + Prosio 文字，无独立图像 logo；原型使用真实文字品牌，不杜撰新 logo。此为工具 UI，不需要摄影或插画。数据均是明确标记的示例，不读取真实用户账户。

## 固定内容
Pro 月费 US$9.90。权益文案为「本地听写不限量」「每月 600 分钟云端智能整理」「云端额度用完，自动继续本地听写」。云端额度按订阅账期重置，不结转；具体下一次示例为10月27日。普通状态示例已用180，剩余420分钟；临界剩余30分钟；耗尽0分钟，本地继续。不能声称本地具有相同智能整理、翻译或 Ask 能力。独立改写、翻译、Ask 的商业额度尚未定稿，原型不承诺无限或虚构次数。价格是否另计税由实际结账显示，原型注明税费以结账为准。取消续费当期继续生效，到期仍可本地听写。免费本地作为提案默认，待用户确认。

## 输出及交互
每版单文件 HTML/CSS/JS，内嵌所有资源，无依赖、无真实支付请求。统一评审画布1440×1000，内容布局在首屏展示完整的主要 UI（含账户/购买窗口、菜单栏状态、听写状态）。原生窗口可维持520×460，若方向需要扩大必须明确提案。三版结构必须不同。页面外部小工具栏标注「交互原型 · 示例数据」，提供按钮 data-state="normal"、"near"、"empty"、"signedout" 切换状态。可使用其他交互。主要操作包含管理订阅（仅模拟门户对话框）和登录/开通（模拟邮箱验证码及托管结账说明，不发邮件、不扣款）。所有按钮有反应，原型提示明确，不能暗示实际购买成功。提供 dialog 关闭功能。临界不打断，耗尽显示「已切换本地听写」「10月27日恢复云端额度」，HUD强调听写继续而非错误。

正文≥14px，次级说明≥12px，主体颜色对比≥4.5，按钮可键盘使用。不要依赖远程字体。主要屏幕用真实中文，不塞开发术语。截图可以为正常状态，额外耗尽状态可保存。设计说明可置画布边缘，产品内不要出现技术实现、代码或审核流程。页面窄屏允许合理滚动，不遮挡重要按钮。
