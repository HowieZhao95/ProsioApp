# 订阅与不限量本地听写：实施计划

状态：UI 三方向待用户确认。当前只新增原型、设计规格和计划，尚未修改正式 App 或支付代码。

## 待确认产品提案
- US$9.90/月，一个套餐；每订阅月600分钟云端智能整理，未用完不结转。
- 本地听写不限量；默认提案为未登录、未订阅和订阅到期也可使用。需设备支持、权限与本地语音资源就绪。
- 云端只剩30分钟时轻量提醒一次（阈值为设计提案）；耗尽后自动本地，显示下次云端恢复日期。
- 展示「本地听写不限量 · 每月600分钟云端智能整理」。不宣称无限云端、不保证两种模式效果相同。
- 邮箱验证码登录，Stripe托管结账与管理订阅。无年付、无加购额度。
- 独立改写/翻译/Ask额度未定。本轮UI不承诺这些无限使用，发布前必须明确额度与计量规则。

## UI 选择后执行
1. **计量基础**：服务端按真实云端音频秒数计费（界面显示分钟），本地识别及本地文字接受不扣云端分钟。原子预留→成功结算→失败释放；录音超剩余额度整段本地处理，避免截断听写。多设备并发不透支。同一操作重试复用结果，客户端遥测与收费账本隔离。
2. **账户与权益**：邮箱验证码、可撤销会话、钥匙串凭证、退出/删除账户。订阅账期、额度和权益由后端返回；不以设备时钟判断重置。不将不同邮箱自动合并账户。
3. **Stripe**：服务端创建绑定内部用户ID的Checkout；验签、去重、乱序协调webhook；Customer Portal管理取消与付款方式。支付返回页仅查询权益，不自行授予。取消续费到当期结束仍有效，到期保留本地。
4. **SwiftUI**：按选定原型实现账户页、邮箱验证码流程、菜单栏额度与轻量提醒。云端不足时下一次请求走本地；正在进行的录音完整保留并本地完成。不在说话中强制弹购买窗口。额度恢复后明确显示云端可用。语音资源缺失时指引准备本地听写，不能假装识别成功。
5. **成本闭环**：独立Compose计量与硬限额、速率/并发限制、音频长度校验；跟踪模型费用与付费收入。20%净利是经营目标，不能仅凭600分钟上限认定实现。
6. **正式分发**：Developer ID签名、公证、干净安装验证。配置真实邮件和Stripe测试环境，然后才进行上线验收。

## 验收重点
- 修复已有审计的4个失败：超额请求、重试重复模型成本、客户端伪用量覆盖、Compose无计量。
- 真实数据库测试并发预留、释放、跨用户隔离；支付测试重复/乱序通知、续费、失败、退款、取消/到期。
- UI测试：未登录→验证码→购买→权益刷新；420/30/0分钟；额度不足且录音长于剩余；跨设备同时耗尽；断网/云端故障回退；本地资源缺失；账期恢复；退出账户。
- 本地、失败、幂等重试不多扣；无需云端时不上传音频。现有听写快捷键、跨应用粘贴和选区能力不回退。
- 当前原型操作均为模拟，不会发送邮件、扣款或修改订阅。UI确认不等于外部账户已具备上线条件。
