# Prosio Capture · 已选 C 柔和悬浮

用户选择与原话保存在 direction-approved.md；无需再次三方向确认。index.html 作为已选方案入口，A/B 保留追溯。本轮只改交互原型，不改原生生产代码。

主流程：入口/快捷键 → 框选 → 原地标注 → 复制/保存退出。没有结果卡片与独立编辑窗口。删除裁剪、调整选区两个按钮，八个角/边手柄直接调整范围，最小 24×24 CSS px。内部默认拖动移动；选中工具后内部拖动绘制，Esc 回到移动模式，已完成标注保留。文字是固定“重点·示例”，不是完整文本输入控件。

选区接近屏幕安全边界、示例窗口、文档内容容器、标题、小标题、决策列表及段落的真实 DOM 边界时吸附。进入阈值 8px，保持到 16px 才解除，显示细对齐辅助线。目标由 querySelectorAll 的 getBoundingClientRect 收集全部已知示例块，不声称能识别其它原生窗口或任意网页 div。

工具条使用独立 fixed 视口定位，尝试下、上、右、左，沿边进行横向或纵向 clamp。没有外侧空间时可以浮在选区内，操作不得隐藏。选区拖拽无过渡动画，不产生跟手延迟。颜色和线宽仅在适用工具选中时出现：矩形/箭头/画笔提供两项，文字只颜色，遮挡不展示两项。轻柔材质、细分隔与圆角沿用 C。

标注存储为固定快照的视口全局坐标；渲染时减当前选区原点。移动或改变左上边界不会让已完成图形跟着框偏移。超出选区的标注自然裁切。所有复制/保存为模拟，不读取真实截图、不访问设备、不写文件、不修改系统剪贴板。

浅/深/跟随系统明确可切换，仅 Prosio 遮罩、工具条、句柄等变化。示例文档整棵子树的颜色、背景、字体、尺寸固定；主题切换不改变底图。截图统一 1440×900；900×760 另验证四角、小选区与满屏操作可达。录屏保留原有模拟，不扩展。
