# Prosio 启动导引设计说明

用户原话：做一个贴心的应用启动导引界面，介绍 APP 的功能与用户需要先进行的各种设置，参考 typeless 等应用，启动页面可以让用户体验各种功能，简洁凝练用户理解心智要低。

## 对需求的理解

这个导引服务于第一次打开 Prosio 的 Mac 用户。用户不是来学习权限术语、技术模式或产品架构的，他只希望知道这款应用能帮自己做什么、接下来按哪里、操作成功以后会发生什么。Prosio 已经包含语音输入、截图、录屏、录音转写、演示辅助、便签与 Agent 监控，如果在首屏平铺七份说明，再连续要求所有权限，新用户会在得到价值前承担过多决策。因此导引要以一次容易成功的体验为核心，每次只呈现一个明确任务：先让用户看到一句话变成文字，再说明实现这个任务需要的设置，最后用一个安全的练习区让用户亲手完成。完成第一项后，其余功能仍能随时体验，但不作为退出向导的前提。贴心来自可预期的反馈：权限已经开启就不重复要求，拒绝之后说明怎么恢复，返回应用后检查状态；快捷键冲突给出具体替代键；暂时不想录音的人也能先体验无需权限的便签与演示。简洁不是删去必要信息，而是把信息放在发生作用的时候。基于这个理解，直接做三个不同方向的真实版本供用户选择。

## 共同设计约束

- 产品：本地代码库中的 Prosio macOS 菜单栏应用；现有 UI 为原生系统字体、浅灰背景、中性面板，交互项少量蓝色。保留 waveform 标志与 Prosio 字标。
- 目标人群：第一次使用的新用户，不假定用户了解 macOS 权限术语或知道菜单栏应用在哪里。
- 主要场景：首次启动自动展示、菜单栏重新打开导引、未授予权限时进入对应设置步骤。正式实现应记录已完成与暂缓状态，重新进入时按当前系统权限恢复。
- 核心功能：语音输入包含直接输入、整理表达、翻译、选文改写；屏幕截图包含选择区域、标注、翻译；便签可记录想法；扩展体验包含录屏、会议转写、演示光标和 Agent 任务。
- 信息层级：一句价值说明、一个体验区、一个主要动作、必要设置提示。避免大段产品宣传文案、装饰图标、订阅推销、强制登录或一次索取所有权限。
- 设置：语音需要麦克风与辅助功能。Fn 为默认语音键，选择 Fn 时提示关闭系统 Fn 动作；其他右侧修饰键可替代。截图/录屏需要屏幕录制；Option 独立截图快捷键的输入监控为条件权限。纯文字便签不需要录音和屏幕权限；演示的基础光标/倒计时不需要麦克风。录屏摄像头仅在启用时请求。云端能力的账号与服务连接在实际使用时检查，不能假装已配置成功。
- 权限被拒绝：显示具体系统设置路径和返回后复查动作，保留用户在导引中的位置；不能用“继续 anyway”模糊成功状态。
- 交互原型：权限、录音、转换结果与任务为标明的示例，不访问真实麦克风或系统权限；页面外统一标注原型边界。不能声称完成了生产功能接入。
- 输出尺寸：三版均使用1060 × 680 的 macOS 窗口内容（外窗 1060 × 720），截图视口 1440 × 900。窄视口允许自然滚动，正文不小于 14 px，辅助标签不小于 12 px；支持键盘导航和 reduced-motion。
- 图片：功能教学本身是界面，不需要摄影或装饰插画。真实产品素材来自已有源码结构与 waveform SF Symbol；HTML 波形是标志的简单几何近似，正式实现使用 SF Symbol。设计中不出现第三方品牌 logo；Typeless 仅在研究说明中引用。

## 三个方向

A 逐步陪伴：白盒画廊布局，单一主线“认识—准备—试一次”，以正文和一个示例作为视觉锚点。轮盘采样 19 秒 → 20 号 Kenya Hara White Gallery，按 Prosio 原生语境迁移；不采用摄影、复杂滚动或极小字体。

B 功能体验台：借鉴已验证 Typeless 官方安装文档中“权限—麦克风检查—引导示例”的连续体验，原生侧栏随时切换功能，未设置项就地打开准备面板。信息与状态一直可见，适合多功能应用。

C 场景工作台：借用 IDEO 的做中学思路，以“写下来、看清楚、记住它”为用户任务建立入口；暖灰桌面、横向任务选择、左右分开的练习区与准备区，避免进入前先读完整手册。

## B 最终实现

五页：语音输入、屏幕截图、桌面便签、更多工具、开始使用。205 pt侧栏；35 pt标题，14 pt说明，12–13 pt辅助文案。每页一个主操作；底部固定前后导航与居中页码，权限和快捷键收进就近设置面板。深色使用较亮的灰蓝强调色；原生窗口按可用屏幕尺寸设置，内容可纵向滚动。首次启动展示、暂缓/完成状态与体验状态分别持久化，菜单栏可再次打开。
