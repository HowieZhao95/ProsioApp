# Prosio 视觉依据

资产来自本地 Apps/macOS/Prosio/UI/MenuBar/MenuBarShell.swift：waveform SF Symbol 与 Prosio 字标，系统字体、中性面板、细边界；蓝色表示可操作项，红色用于实际录音状态。现有 ProsioPalette 蓝紫色仅少量用于可操作强调，不使用大面积渐变。

HTML 以简单竖线近似现有 waveform 标志；正式 SwiftUI 使用原 SF Symbol。产品私有、无公开 logo 文件，本地代码是资产依据。三版共用这一标志并内联，无外部图片或字体依赖。A 白灰极简、B 原生蓝灰、C 暖灰与少量蓝色分别解释同一产品气质。

Typeless 是研究参考，不作为导引画面中的品牌，因此不在导引中放置其名称或 logo。
