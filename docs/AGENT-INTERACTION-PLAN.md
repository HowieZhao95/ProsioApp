# Prosio Agent 阶段 2 与 3 实施和验收计划

## 目标与当前证据

阶段 2：让用户知道哪个任务在执行、在等待回答还是审批、状态来自何处、多久前确认，以及下一步可以做什么。
阶段 3：在 Prosio 中对原任务回答问题、补充要求和请求中断，展示真实回执，处理过期、重复、离线和多端竞争；语音先进入可编辑草稿，由用户发送。

现有实现支持本机 Codex 日志、已有 Unix WebSocket 实例及桌面宿主 IPC 查询。2026-10-03 本机默认目录没有 App Server 控制套接字，但已有桌面宿主 IPC 可用于读取原任务、回答实时结构化问题、补充运行中要求和请求中断。日志问题不能当作当前服务器请求；不得根据日志 call_id 构造审批响应，不启动另一个 Agent 冒充原任务。

### 已实现的连接边界

| 来源 | 状态 | 回答问题 | 运行中补充 | 中断 |
|---|---|---|---|---|
| 桌面宿主 IPC | 实时状态及完整结构化问题 | 同一 request/turn，发送前核对，发送后核对回答记录 | 按用户选择绑定同一任务当前执行的轮次；命令 ID、实际轮次和输入记录三者核对，轮次变化单独提示 | 使用 expectedTurnId，终止状态另行核对 |
| 已有 App Server 控制连接 | 实时状态 | 不接管另一个客户端拥有的请求 | expectedTurnId + 稳定命令 ID | expectedTurnId |
| 本地日志 | 带时效的近期状态 | 禁用 | 禁用 | 禁用 |

发送成功、原任务记录输入和本轮中断分别展示。回答请求消失不等于回答生效；网络结果未知不自动重发。桌面协议按本机版本核验，未知版本拒绝控制。

2026-10-03 用户明确选择“按同一任务发送并核对实际回执”，替代桌面补充入口此前要求调用者指定轮次的限制。该语义仅适用于补充要求；问题回答、中断和已有 App Server 的控制继续保留对应轮次约束。补充不会创建新会话或启动空闲任务，不能代替操作审批。轮次变化不丢弃该任务未发送的补充草稿。

## 工作顺序

1. 状态模型：区分回答与审批，结构化保存问题和选项、任务/轮次/调用身份；未知字段保守降级。显示状态证据和时效，停止监控不保留“实时”语义。
2. 状态界面：保留当前窗口结构，展示待处理原因、问题卡、选项说明、来源和当前可用操作；记录缺失时说明需要回到来源查看。
3. 控制连接：独立于只读观测，连接已有实例，验证当前 thread/turn；不得修改用户配置、启动/恢复原任务或默默扩大权限。控制连接不可用时明确禁用操作。
4. 交互：桌面补充按上述任务语义路由，并以稳定命令 ID 核对实际接收轮次；已有 App Server 补充使用 expectedTurnId。中断明确为请求，等待终止证据。结构化回答只使用实时服务器请求身份与对应响应协议。
5. 回执：发送中、服务器接受、已确认应用、需要澄清、未送达、结果待确认、已失效。RPC 接受不能当作要求已应用，问题 resolved 也可能是取消而非回答生效。
6. 一致性：每任务单个在途操作，命令稳定身份，未知结果不得自动重发；切换任务不串草稿，问题更新后旧答案失效，恢复连接先核对原请求。
7. 语音：复用本地转写入口，捕获任务/问题目标及选项词汇，将文本写入可编辑草稿，一次确认发送；取消不发送，焦点改变不改变目标任务。不自动替用户改写识别内容。
8. 验收：独立无宿主模型/协议测试、隔离主应用构建、合成数据浅深色界面检查、真实原任务端到端验证，最终逐项报告证据。

## 验收矩阵

| 要求 | 证据与通过标准 |
|---|---|
| 状态准确 | 测试覆盖运行、回答、审批、结束、中断、错误、未知字段和失效；运行状态与真机对照 |
| 问题完整 | 保留问题 ID、文字、选项说明；多问题不丢失；call/turn 绑定测试 |
| 状态时效 | 暂停和读取失败不继续宣称实时，三分钟后的日志活动降级 |
| 原任务交互 | 真机证明回答进入原问题轮次、补充进入同一任务并核对实际轮次，原任务继续 |
| 权限边界 | 控制操作不改权限配置；审批需单独语义；语音“继续”不扩大授权 |
| 回执诚实 | 假服务与真机分别验证接受与应用，断线后只显示待确认 |
| 重复与过期 | 双击、网络恢复、旧轮次、问题更新和多端抢答测试 |
| 语音 | 真机采集、预览、编辑、取消、绑定目标和发送验证 |
| UI | 合成数据浅色/深色截图及实际点击检查 |
| 主应用 | 隔离构建通过，不替换当前运行应用 |

## 完成门槛

全部验收项有对应证据后才完成。控制接口不支持接管现有桌面请求、或本机没有可连接实例，均应报告真实缺口，不能用假服务通过代替真机闭环。Apple Watch 不在本次范围。
