# 演示工具 MVP

## 范围与入口

菜单栏「演示」与设置「演示」提供三个独立模块及演示会话：

- 鼠标轮廓、左右点击区分（Control + 左击视为右击）、拖动保持反馈、静止 1.5 秒隐藏、仅点击反馈模式；尺寸与三种强调色即时生效。
- 按键显示支持「仅快捷组合」（默认，Command / Control / Option + 主键）和「全部按键」（显式选择后显示普通打字），合并修饰键、单个键帽、释放后停留、长按重复复用当前键帽、30 秒丢失释放兜底。显示在产生事件时鼠标所在屏幕底部；菜单提供无需输入监控权限的 3 秒测试键帽。
- 屏幕及系统空闲防休眠，手动 15 / 30 / 60 / 120 分钟或无限、运行中追加 15 分钟、独立会话来源。停止其中一个来源不影响另一个。

放大镜、隐藏桌面、背景聚焦、自定义热键、可拖动布局和复杂主题留待后续。没有画面采集，也没有增加录屏权限要求。

## 状态语义

- 默认会话启用三项；修改预设只影响下一次会话。
- 会话启用的鼠标与按键行标记「会话启用」。会话外可独立开关；会话中的视觉暂停控制整个演示视觉。
- 会话采用独立所有权，不恢复旧快照：结束只移除会话来源，保留前后手动启用的模块。结束后恢复手动视觉，隐私急停除外。
- 暂停视觉立即移除鼠标窗口、清空键帽、卸载按键监听；防休眠继续。
- 隐私急停是粘滞状态；结束或重新开始会话均不会解除。只有明确点击恢复才解除，不回放任何输入。
- 系统安全输入期间自动清空并暂停键帽；不承诺识别所有网页密码框或其他敏感内容。Prosio 自身默认排除；可用逗号分隔 Bundle ID 添加排除应用。
- 锁屏、用户切换、系统休眠释放所有演示保活来源，视觉进入隐私暂停；解锁不自动恢复。再次保活需手动启动或结束并重新开始会话。
- 截图选择期间自动临时抑制演示视觉，不改变会话或保活状态。显示器变动清空所有旧浮层后按当前状态重建。
- 偏好持久化，运行状态、按键、保活截止时间不持久化；重启不自动开始演示或保活。
- 所有权限请求由用户发起：关闭原有启动时语音授权弹窗，语音面板仍提供原有授权入口；麦克风已授权时才预热音频图。只开保活不会要求输入、麦克风、录屏权限。

## 代码地图与调整点

`Apps/macOS/Prosio/Presentation/`：

| 路径 | 职责 / 调整点 |
| --- | --- |
| `Domain/PresentationState.swift` | 会话来源、视觉暂停和隐私急停；单个快捷组合生命周期 |
| `Domain/PresentationPreferences.swift` | 独立偏好、默认预设、参数范围与恢复默认 |
| `Platform/AwakeService.swift` | 注入式电源接口、原子建立两种系统保活 assertion、按来源释放与追加时长 |
| `Platform/PresentationClock.swift` | 跨休眠的单调时钟，避免修改系统时间延长保活 |
| `Platform/PresentationInputMonitor.swift` | 只读事件监听、权限与安全输入、键盘标签；排除应用期间保留被严格门控的监听，避免切回应用后重装监听造成首次快捷键遗漏 |
| `Platform/PresentationOverlays.swift` | 统一小型浮层、屏幕坐标、点击穿透、显示与回收 |
| `Integration/PresentationCoordinator.swift` | 生命周期、环境变化、应用排除、状态与服务协调 |
| `UI/PresentationViews.swift` | 菜单操作、设置、模拟预览 |

集成点仅为 `AppEnvironment` 的实例/启动/退出/截图抑制、现有菜单壳和设置入口。使用原生 SwiftUI/AppKit 样式。没有新外部依赖。

计时器：鼠标高亮启用时通过屏幕 CADisplayLink 更新位置（跟随刷新率，上限 120 Hz），只改变窗口原点，不重复设置尺寸或布局，协调器以 10 Hz 处理权限、安全输入、到期和环境状态；倒计时 UI 按秒更新。监听失败每 2 秒重试，显示明确状态。视觉暂停后移除鼠标计时器与输入监听。

## 验证与人工验收

自动测试：`Apps/macOS/ProsioTests/PresentationTests.swift`，逻辑测试不启动 Prosio、不申请 TCC 权限、不创建真实系统保活。覆盖会话幂等/恢复、急停不可隐式解除、按键重复/释放/超时、来源独立、追加截止时间、到期、系统请求失败、无效参数与偏好恢复。

真实机验收（需使用者主动授权，不通过测试自动改变系统权限）：

1. 仅启动手动保活：无无关授权弹窗；用 `pmset -g assertions` 确认 Prosio 的 display/system idle assertions，停止后消失。
2. 手动保活 120 分钟 → 开始会话 → 暂停视觉 → 结束会话：手动保活仍继续。再停止手动保活，Prosio assertions 消失。
3. 授予输入监控并返回：在其他应用按 ⌘⇧S，组合为一个键帽；按住时保持，释放后按设置时长消失，方向键重复不堆叠。
4. 急停后输入多个组合，恢复后不补播；系统安全输入和排除应用不显示任何键帽。
5. 鼠标移动、快速点击、右击、Control + 点击、长拖动、静止后首次点击、屏幕四角及不同坐标/缩放的显示器：不抢焦点、不阻止原应用操作。仅点击模式反馈停留原位。
6. 锁屏/睡眠/切换用户、输入权限撤销、外接屏拔插及全屏 Spaces：无残留键帽，锁屏后保活释放，视觉需明确恢复。
7. 退出应用后没有残留窗口和 assertions。仅共享单窗口时不保证独立浮层可见；整屏共享需观众端确认。

MVP 边界：不阻止手动睡眠或合盖；不是全域隐私脱敏。全屏、跨屏热插拔、远端共享可见性与 TCC 撤销需上述实机验收，单元测试和静态预览无法代替。

## 实机复测与修正

修正用户报告的跟随卡顿及切换应用后可能漏掉首个快捷键：鼠标从 30 Hz Timer 改为屏幕刷新回调，只移动窗口原点，静止时避免重复窗口服务调用；排除应用仍拒绝解码事件，但不反复卸载/安装键盘监听。隐私暂停、安全输入、权限撤销仍卸载监听。

- 已将同一开发签名的修正版安装到 `/Applications/Prosio.app`，旧版留在忽略的 `build/`，退出后重新以正常模式启动。临时验收窗口和诊断已关闭。
- 最新 hostless macOS 回归：196 项测试、31 个套件通过，含 12 项演示测试。结果：`build/presentation-live-fix-tests-final.xcresult`。
- 本机只有一块 1680×1050、2× 显示器；5 秒采样中的屏幕刷新回调约 58.8 次/秒。该指标是刷新回调频率，不是完整的视觉延迟或持续性能承诺。测试期间最慢回调间隔包含原生菜单/自动化/编译负载，尚未做专门的长时间帧延迟基准。
- 输入权限已通过：实际运行的只读键盘 tap 事件掩码包含 keyDown / keyUp / flagsChanged，监听可用，安全输入未开启；实机诊断收到 4 次 keyDown，其中 2 次生成快捷组合键帽，之后键帽清空。自动化工具直接向目标应用发送的键盘动作不能代替物理全局输入验证。
- 原生 UI 操作通过：手动 120 分钟与会话同时保活、追加 15 分钟、暂停视觉、急停、结束/重新开始会话不隐式恢复隐私、明确恢复、分别停止两个保活来源、会话结束保留手动视觉、尺寸/停留滑块修改并还原、仅点击模式切换并还原。
- 用系统 power assertions 验证暂停/急停/结束会话保留手动保活；停止最后一个来源后释放。带着手动保活、会话、鼠标和按键监听退出，确认无进程、覆盖窗口及本应用 assertions 残留；正常重启后无演示浮层，运行状态不被持久化。
- 原生设置预览在实际窗口正常显示；测试输入文稿保存到本地 `docs/evidence/presentation-mvp/live/presentation-test-input.rtf`。

证据：`docs/evidence/presentation-mvp/live/`。DEBUG 模式可显式设置 `PROSIO_PRESENTATION_TEST_PANEL=1` 复用正式视图进行稳定窗口验收；`PROSIO_PRESENTATION_DIAGNOSTICS_PATH` 写入本地计数与状态，不记录键码、标签、输入文字、应用名称。正常启动不启用这些入口。

## 按键不可见跟进

旧版只显示快捷组合，普通字母不会显示；现已提供持久化的全部按键选项，同时保留默认的快捷组合模式。新增屏幕键帽测试按钮，示例持续 3 秒，无需输入监控授权；安全输入、视觉暂停和隐私急停仍立即清空示例。

本轮已构建、签名、替换并重启应用。199 项测试、32 个套件通过（`build/presentation-keycap-mode-tests.xcresult`）；新增普通/特殊按键模式测试及实际窗口绘制测试，验证非透明像素、点击穿透、不抢焦点、隐藏清除。原生 UI 验证模式选择、提示与默认恢复；本地采样确认示例窗口出现并被隐私急停清除。此前仅有输入/生成计数，不能作为用户实际可见的证明；真实实体键盘快捷键可见性仍等待用户确认。证据：`docs/evidence/presentation-mvp/live/keycap-mode-verification.json`。
