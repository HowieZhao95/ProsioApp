# 每日便签实施与验收

2026-10-03。用户审核通过 A 极简浮窗后实施，后续按用户要求移除底部“已保存 / Aa”整行。

## 已实现

- 原生 NSPanel，可拖动、调整大小、置顶、隐藏；记住位置并纠正完全离屏的窗口。
- 菜单栏便签入口；可选全局快捷键，默认 ⌃⌥N，注册冲突在设置提示。
- 头部 34 pt，横向 padding 8 pt；日期、置顶；历史日期附回到今天图标。忽略原生标题栏顶部安全区，避免额外空白。正文上下 16、左右 20 px。
- 底部没有常驻状态或格式栏。按最新审核移除浮窗省略号及整个菜单；便签设置从 Prosio 控制中枢的“便签设置…”进入，保存异常才显示提示。
- 每日任务基于 Markdown 勾选项：标题栏常驻今天的未完成数量；日历日期格显示完成/未完成数，选择日期后在日历下方列出当天任务。勾选后实时更新，查看历史日期仍显示今天的数量。代码块、注释和普通正文不计为任务。
- 本地 Milkdown WYSIWYG Markdown 编辑器，常用 CommonMark/GFM、任务项、表格；不支持的语法以源码保留，未编辑的原文不被格式化。无 CDN 或网络请求。
- 每个本地日期唯一 YYYY-MM-DD.md；月历内容圆点、历史切换、快速回到今天，未来日期不可编辑。跨午夜更新今天标记，不替换正在编辑的日期。
- 存储位置仅在设置里手动选择；未配置时按日期保存恢复草稿。1 秒防抖保存、隐藏/切换/退出前读取最新编辑状态并保留恢复副本。
- 写盘采用原子替换，外部修改/删除不自动覆盖。目录迁移先检查全部冲突、保留原文件，目标目录的未保存草稿同样受保护。
- 主题、字号、置顶与快捷键设置；错误重试、磁盘版本预览/采用，采用前备份当前编辑。

## 复现

见 `tools/notes-ui-validation/README.md` 与 `Apps/macOS/Prosio/Notes/Editor/README.md`。

不支持图片附件及任意 Markdown 扩展；这类内容会保留原文并提示源码模式。超过 5 MB 的文件或无效 UTF-8 不会被修改。构建未替换用户正在运行的应用实例。

任务原生验收：实际勾选后标题栏从今天 2 项待办变为 1 项；磁盘保存为 [x]，日历同步显示已完成 1 / 未完成 1，并列出两项任务的对应状态。选择昨天后预览切换为昨天的任务，今日待办数量保持 1。

视觉精修：头部仍为 34 pt，水平留白 10 pt；今日待办使用轻量胶囊。正文上下 20、横向 22 px；标题/段落/任务行明确分级，18 px 复选框与文字对齐。日历居中展开，18 pt 内边距、40 pt 日期格与柔和选中底色；任务预览使用 13 pt 字体及舒展行距。移除编辑器原生样式叠加的段落 padding 和双重引用竖线。

显示/隐藏动效：原生窗口透明度淡入 180 ms（ease-out）、淡出 140 ms（ease-in），不移动窗口位置；系统减少动态效果时使用 80 ms 轻量淡入淡出。关闭前仍保留最新内容，快速反向操作会取消过期隐藏请求及动画完成回调。

动画隔离运行检查通过：显示结束可见、隐藏结束不可见、淡出期间反向唤出保持可见、保存过程中的隐藏请求被重新唤出取消。四项结果均为 true。

系统节假日：通过 EventKit 读取 macOS 已订阅的节假日日历，不创建、编辑或删除系统事件。控制中枢 → 便签设置 → 系统节假日可开启、连接和选择来源；默认关闭，首次由用户授权。自动识别节假日名称的日历，可手动指定自定义来源，只显示全天事件。跟随系统事件更新通知、权限状态和当前展示月份刷新。日期格显示节日简称，悬停显示完整名称，当天任务预览同时显示全部节日名称。

macOS 不提供其它日历应用界面中“勾选显示哪些日历”的状态，本功能跟随系统可读取的订阅来源和所选日历。无订阅、拒绝/撤销授权、来源被删除时显示对应提示，不捏造节假日或调休安排。

节假日验证：18 项便签领域测试通过，最新整应用 239 项测试通过。新增验证结束日期排他、多日事件、月范围裁剪、本地时区和重复节日去重；原生设置界面已验证默认关闭且未触发授权。真实系统节假日内容未读取，待用户开启授权后验证。应用构建包含 NSCalendarsFullAccessUsageDescription 和 calendars entitlement。

参考 Apple 官方 EventKit 文档：https://developer.apple.com/documentation/eventkit/accessing-the-event-store
系统订阅说明：https://support.apple.com/guide/calendar/subscribe-to-calendars-icl1022/16.0/mac/26
