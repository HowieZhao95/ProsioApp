# 启动导引实现与验证

2026-10-04。用户选择 B，追加顺序导航、凝练文案与优雅排版要求，已实施到原生 macOS 界面。

## 结果

- 五页：语音输入 → 屏幕截图 → 桌面便签 → 更多工具 → 开始使用。侧栏、上一步、下一步共用进度；底部页码居中。
- 一句标题、一句说明、一个主要动作；设置面板就近出现，保留系统字体、克制灰蓝、统一间距与留白。
- 练习输入区使用真实 NSTextView；语音走现有 DictationController，输入/翻译/选文改写复用生产路由。按启动时的选择范围插入，防止焦点变化把练习文字写到其他应用。
- 截图、便签、录屏、录音转写、演示与 Agent 入口连接现有 coordinator。插画标明「示意」。导引持有的录音、语音或光标体验在关闭时清理。
- 麦克风、辅助功能、屏幕录制、Fn 动作、快捷键冲突、智能服务登录均就地检查；授权状态定期复查。无需权限的便签可以直接打开。
- 首次启动自动展示，进度、真实体验与暂缓/完成分别保存；菜单栏「启动导引」可重开。未设置项保持「稍后设置」，不会伪装成已就绪。
