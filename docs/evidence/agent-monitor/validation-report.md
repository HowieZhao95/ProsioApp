# Agent 监控第一阶段验证记录

日期：2026-10-03。

## 结果

- 最终版本的独立无宿主测试：**24 项测试、4 个测试组全部通过**。
- 完整 Prosio macOS 应用：**BUILD SUCCEEDED**，新增 Agents 源文件及菜单入口已参与构建。构建使用独立生成项目及 `/tmp/prosio-agent-monitor-app-build`，`CODE_SIGNING_ALLOWED=NO`，未安装或启动该应用，不替换正在运行的版本。
- Swift 6 严格并发、MainActor 默认隔离下编译通过。
- 新增文件和菜单改动的空白检查通过。
- 独立原生详情窗口及菜单栏弹出界面浅色／深色渲染均已人工查看。菜单使用真实 MenuBarShell 与 AgentMenuPane，列表可滚动，全部任务与刷新入口位于列表上方。截图使用构造数据，不是实时任务截图。

## 测试组

1. 状态解析：来源优先级、旧 turn 回执、结构化问题与对应工具结果、普通聊天问号、异步问题不冒充阻塞、过期与读取失败、运行实例状态、子 Agent、异常事件。
2. 本地读取：发现已存在的任务与标题、增量完成、部分记录补齐、文件截断／替换／删除、大文件有界读取、缺失目录、符号链接隔离、损坏记录降级。
3. 生命周期：暂停时丢弃仍在执行的扫描结果；待处理和执行中筛选不纳入过期执行状态；菜单任务按待处理、执行中、近期排序并限制五条；首次启动开启、记住显式暂停、退出不覆盖偏好、关闭详情继续监控。
4. 运行实例协议：连接假服务中的现有线程、只发送 initialize/initialized/loaded-list/read、不回答审批、分片及 Ping/Pong、错误握手、超时、大消息和缺失端点。

## 本机只读验证

聚合结果见 [local-observation.json](local-observation.json)：发现 87 个现有会话，来源为 Codex Desktop 60 个、ChatGPT Work / Codex 27 个。该次读取的记录状态为本轮结束 85 个、中断 2 个；这不能用于宣称当时所有桌面 Agent 的真实执行状态。

首次扫描读取约 47.59 MB 会话记录；紧接着第二次扫描未变化的会话日志读取量为零。两次扫描合计约 2.83 秒。计数不包含标题索引读取或目录元数据操作。

## 未验证及后续阶段

- 当前机器没有社区项目使用的 `app-server-control.sock`，因此真实运行实例查询尚未验证。假服务验证的是协议行为，不能代替真机兼容性验证。
- 本地日志可能在本轮结束时批量写入；执行中的步骤可能暂时不可见。UI 明确显示日志来源、更新时间和过期降级。
- 普通 ChatGPT 聊天／纯云端 Agent 任务尚未接入。
- 不包含向原 Agent 回复、审批、暂停、语音回传或手表端。这是此前四阶段中的接入与状态观察阶段。
- 主应用中菜单点击及原应用打开动作未在用户正在运行的 Prosio 上执行，避免干扰现有会话。系统状态栏动态图标和计数已通过完整应用编译，弹出菜单通过独立原生预览验证。
