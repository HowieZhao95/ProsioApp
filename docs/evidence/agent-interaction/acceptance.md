# Agent 阶段 2 / 3 验收记录

日期：2026-10-03。结论：本机桌面交互闭环功能验收完成。范围为状态展示、原任务回答、运行中补充、中断及可编辑语音草稿；Apple Watch 不在本次范围。

## 用户确认的补充行为

用户明确选择“按同一任务发送并核对实际回执”。桌面补充发送给选中任务当前正在执行的轮次，再核对稳定命令 ID、实际接收轮次和完整输入记录。若实际轮次发生变化，显示“补充已进入同一任务的新轮次”。不启动空闲任务、不创建另一个会话。问题回答和中断仍绑定原问题及原轮次。

## 原任务真实验收

所有真实控制操作均限用户授权的临时聊天“Prosio Agent 闭环验收”（`01a0fe8c-d424-7c40-97e8-4a54cd21704f`）。测试开始提示使用聊天工具，实际回答、补充和中断均从 Prosio 验收界面发出。没有启动替代 Agent，没有修改原任务权限或配置。

- 只读连接：已有桌面宿主返回原任务与实时状态；增量读取避免反复扫描全部日志。
- 文字回答：Plan 模式同步问题显示完整选项及说明。在 Prosio 发送“选择方案 A，但面向初中生，先出草稿，不发布。”后显示原任务输入记录回执；独立读取原聊天确认同一轮次完整复述并结束。
- 单选回答：新的同步问题直接点击“方案 B”提交，原任务最终回复核对方案 B；刷新延迟期间旧选项禁用，不能重复发送。
- 中断：等待任务中点击“请求中断本轮”，先显示已接受；核实后显示原轮次已中断，独立读取原聊天确认 `status: interrupted`。
- 运行中补充：Prosio 发送“仅补充当前任务：面向初中生，文案简短，先出草稿，不要发布。”，回执显示原任务已记录输入，并清空已发送草稿。独立读取原聊天确认原轮次 `01a0fec2-2841-78f3-83f3-33f5c8a6760c` 包含完整用户输入，随后完整回复“同一任务已收到补充：仅补充当前任务：面向初中生，文案简短，先出草稿，不要发布。”，该轮次 `status: completed`。见 [补充证据](real-supplement.json)。

## 语音证据与质量边界

用户明确授权麦克风测试。验收应用使用真实音频采集和本地转写；本机播放中文测试句，录音中显示识别文字。第一次取消后回答框为空、原问题继续等待；第二次停止录音后进入可编辑草稿，没有自动发送。校正为“选择方案 A，面向初中生，先出草稿，不要发布。”并明确发送后，独立读取原任务确认同轮次完整复述。录音面板退出后停止采集。

增加录音目标的选项词汇后，使用真实本地转写引擎按实时节奏输入 16 kHz 单声道中文语音样本。基线漏识别“方案 A”，加入当前任务词汇后得到“选择方案 A的面向初中生，先出草稿，不要发布”，保留“方案 A／面向初中生／先出草稿／不要发布”四项语义。相关两项音频测试通过，结果见 [语音回归记录](voice-quality.json)。识别内容不被程序自动改写，仍由用户检查和编辑。

扬声器回录出现误词和漏字，合成语音样本也存在语法和标点误差。这些证据证明本地转写、目标绑定、完整草稿与明确发送链路；不证明真人自然语音准确率、免编辑体验或上线质量指标已经达标。后续上线指标应使用真人语音和目标设备测定。

## 接入范围与清理

本次完成的是已接入本机桌面任务的功能验收。普通 ChatGPT 聊天、云端任务及其他 Agent 来源尚未接入，Apple Watch 通知和通信链路留待下一阶段。

Default 模式异步问题在当前宿主中显示为普通消息，不产生实时结构化请求；回答验收使用用户切换到 Plan 模式后的同步问题。未显示结构化请求时，不构造回答接口。操作审批继续在来源应用处理。

本机没有 App Server 控制套接字，因此该路径仅有假服务测试；真实回答、补充和中断通过已有桌面宿主 IPC 验证。临时聊天在验收后归档，验收应用退出。
