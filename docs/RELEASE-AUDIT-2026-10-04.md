# Prosio 上线前审核 · 2026-10-04

**结论：当前不满足公开上线标准。可继续作为受控内部测试候选，不能标记为正式商业版。**

本次完成现有功能封版范围、静态审查、全量自动测试、依赖安全检查、正式构建检查及可复现问题修复。首次审核发现基础组件 2 项失败、商业化审计 4 项失败；修复后回归通过。没有发布、部署、应用真实数据库迁移或替换用户正在运行的应用。

**后续本机实测已完成并更新本机安装版**，原应用已备份。发现并修复暂停续录片段重叠、语音练习焦点错误，补齐录屏无障碍选择；最终原生回归 322 项通过，真实录屏与 MP4 完整解码、便签存储、本地语音模型测试通过。公开上线结论仍为阻塞。详细结果、安装身份与实测边界见 [本机实测报告](REALTEST-2026-10-04.md)；此后的发行包以该报告 SHA 与门禁结果为准。

发行渠道尚未得到本轮明确答复，按已有商业化文档的官网下载安装路径检查共同要求。当前产物为本地签名候选；Mac App Store 的沙盒适配属于另一项发布条件。本报告不把“编译成功”“单测通过”视为真实云服务、设备或商店验收通过。

## 功能封版

本轮冻结现有交互与功能范围，仅允许错误、安全、性能及验收修复。不得同时增加功能、变更订阅价格或扩大兼容平台承诺。现有公开 Swift 协议与主要 API 形状保留；计量规则安全修正见 docs/API.md。

完整 macOS 候选构建支持 arm64 + x86_64，最低 macOS 26。Intel **编译通过不等于 Intel 真机验收通过**。不得宣称支持更早系统。

## 本轮修复与分析

| 问题 | 根因与影响 | 修复 |
|---|---|---|
| 诊断记录间歇损坏 | 文件刚出现便可能被读到，JSON 尚未写完；首次组件测试复现 2 次 EOF | WAV/JSON 使用原子写入，session.json 最后完成；原有解码测试恢复 |
| 默认留存原始录音 | 每次听写都可能在本机保留音频及文本，超过普通诊断所需 | 新安装默认关闭；保留用户明确保存的设置，不擅自删除既有资料 |
| 剩余额度可越界 | 只检查已用额度，没有加上本次音频；并发请求各自看见同一余额 | 调用模型前原子占用时长；SQL 同用户/月锁包括待处理听写与会议；不允许超额 |
| 重试重复调用模型 | sessionID 只保证计量不重复，不保证推理不重复 | 用户+任务 ID 保存请求指纹与状态/响应；完成任务复用结果，待处理或不同正文返回 409 |
| 客户端操纵计量 | 客户端可以先报 0 占用同一任务 ID，阻止权威写入 | POST /api/usage 保持 204 兼容应答，但不再写计费账；移除桌面重复上报 |
| 跨用户任务 ID 冲突 | 原始账表使用全局唯一 sessionID | 改为用户+任务复合唯一；SQL 迁移及跨用户测试覆盖 |
| 文本/极短音频成本无独立约束 | 音频分钟不能限制文本调用次数，也不足以限制极短音频调用成本 | 所有接受的模型操作另计请求上限；生产需显式设置，不用于定义价格；失败/取消也计调用，缓存重试不新增 |
| 不可信会议时长 | 上传字节数一致不能证明客户端所报时长；服务推理后才看到真实时长 | 暂停生产会议云创建，列为功能封版排除项；本地功能保留 |
| 开发账号冒用 | PROSIO_DEV_AUTH=1 可让任何邮箱取得 token | 两种 production 环境都固定 404，环境开关不能开启 |
| 数据库缺失却继续服务 | 自动使用内存，重启后丢失账号、词典和计量 | 生产缺 DATABASE_URL 时拒绝服务；不会静默退回内存 |
| 传输与配置风险 | 远程 HTTP 可发送 token/文本；开发服务偏好可被带入 Release | 远程请求要求 HTTPS；Release 使用构建配置域名，忽略开发地址偏好；开发界面提示更改地址需重启 |
| 服务内部信息外泄 | 非预期异常/上游详情被原样发送给客户端 | 生产使用通用服务错误，非预期日志隐藏错误原文；签名密钥至少 32 字节 |
| 输入/输出/取消缺少边界 | JSON 整体解析、历史/上下文未完整限长，取消后模型可继续运行 | 实际请求字节上限含分块上传；上下文、词表、历史、输出 token 限制；取消与超时传递给模型 |
| Release 带调试权限 | 全局 XcodeGen entitlements 覆盖分配置设置 | 独立 Release 权限文件、禁用调试注入；通过实际签名产物再次检查 |
| 依赖漏洞 | 不使用的 Next lint 依赖链含 braces 高危；旧 esbuild 开发服务漏洞 | 移除不用的 lint 桥依赖、锁定修复后的 esbuild；干净安装、全量测试、构建及数据库 CLI 再验证 |
| 环境文件泄漏风险 | 原忽略规则不能覆盖所有 .env 变体 | 所有 .env* 默认忽略，仅保留 .env.example；没有打印或改动用户秘密 |

## 验证证据

最终结果与产物检查保存在 `docs/evidence/release-audit-2026-10-04/`。计数按执行的测试计，不将跳过真实服务的测试当作外部服务验收。

- 原生桌面：320 项，hostless 测试，不启动或中断用户现有应用。原摘要只计 262 项 Swift Testing / 38 套，漏计 58 项 XCTest，已依据原 xcresult 校正；后续实测修复后的完整回归为 322 项。
- Swift 基础组件：250 项 / 32 套，覆盖新增远程 HTTP 拒绝与隐私设置断言。
- 服务：414 项 / 23 文件，包含生产安全、请求边界、内存并发与 8 项真实 SQL/PLpgSQL 测试。
- 商业化回归审计：6 项，包括剩余额度、空音频、缓存重试、客户端零计量、独立文本调用计数、开发入口关闭。
- TypeScript 严格检查、Next 生产构建、干净依赖安装、数据库工具运行通过。
- 隔离 Next production 实例的 7 项实际 HTTP 检查通过：健康、开发入口关闭、未登录拒绝、缺数据库拒绝、会议生产禁用、通用安全错误；使用合成 token，未调用收费模型。
- 全依赖扫描 0 漏洞；这是已知公告扫描结果，不是对全部安全风险的保证。
- macOS Release universal 构建与严格签名检查通过；调试豁免与 get-task-allow 均已移除。产物仍未通过正式身份、可信时间戳、生产域名、公证票据与 Gatekeeper 五项门禁，见 `artifact-check.json`。
- 本轮没有提交真实音频给收费模型、没有生产账号/支付端到端测试，也没有外接设备或第三方剪辑器实际验收。既有 UI 截图/原生体验证据可参考 onboarding、recording、capture、presentation 对应目录，不冒充本轮新运行。

PGlite 使用真实 PostgreSQL 引擎执行迁移和存储过程，包括幂等、额度、失败释放、跨用户、会议共享余额、非有限数字及模型次数限制。它只有一个连接，不能证明线上多进程锁正确；正式 Neon 多连接、进程中断、网络断连及恢复演练仍是阻塞项。[PGlite 官方说明](https://pglite.dev/docs/)

## 放行规则与下一轮

现阶段继续内部测试，不新增功能；先完成账号、生产数据库/域名与发行签名三个 P0，再做真实服务和干净设备验收。若商业首发则同时完成支付与权益。会议云、实验 Agent、剪映草稿及尚未验收的外接来源不加入首发承诺。

每次修复只重跑受影响的回归；全部 P0 完成后再对唯一版本包做最终回归，生成 SHA、升级/回滚与分发证据。`tools/release-readiness/check.py` 为只读产物门禁，任何失败都会返回非零状态；它即使通过也不能替代上述业务验收。
