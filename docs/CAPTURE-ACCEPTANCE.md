## 主审查中已关闭的问题

- 语音 Esc Carbon handler 原先不辨别热键身份：现按 signature + ID 路由，不吞截图热键。
- 截图前后 stop/start 会留下重复语音观察链：改为临时 suspension；真正执行延后语音动作前再次检查。
- 反向拖动坐标计算：先规范矩形，补独立测试。
- 已取消保存仍进入 detached writer：补取消传播与原子提交前检查；提交后保留已完成的素材。
- PNG 损坏/缺失与未来版本：重开时拒绝无效记录，保留文件和诊断。
- PNG 成功但 manifest 写入失败：原子目录提交，失败仅清理本次 pending；确定性故障测试通过。
- 空显示器列表/首次 Esc responder/捕获期间焦点：补防护与显式 first responder；真实窗口行为仍待实机验证。
- 同名目标、鼠标在异步枚举期间移动：picker 项绑定原目标序号，显示器加编号，开始时快照鼠标位置。
- 枚举期间取消后仍显示 picker：增加取消检查，并仅中止本协调器自己的 modal。
- 私有 popover 类名判断：移除，菜单视图使用 dismiss。
- 上游版权主体：修正为 Oontz；完整 MIT 文本同时保留在仓库和应用资源中。
